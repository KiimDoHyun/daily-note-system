# daily-note-system

옵시디언 볼트의 데일리 노트를 매일 아침 자동으로 만들고, 어제 못 끝낸 할일을 오늘로 이어붙이고, 오래 방치된 항목은 스스로 정리해주는 macOS 자동화 시스템입니다.

---

## 왜 만들었나

원래 macOS 로그인 시 데일리 노트 파일 하나만 자동 생성되는 스크립트를 쓰고 있었습니다. 노트 파일이 생기는 것까지는 편했지만, 실제 사용해 보니 아래 같은 문제가 반복해서 생겼습니다.

- 어제 못 끝낸 할일을 오늘 노트에 손으로 다시 옮겨 적음
- 며칠째 이월된 항목을 언제까지 붙들고 있을지, 언제 지울지 매번 판단
- 완료한 일이 어제 노트에만 남아 있어서, 이번 주에 뭘 했는지 되짚기 어려움
- 월말에 한 달 동안 완료·보류한 항목을 모아 보려면 노트를 하나씩 뒤져야 함

파일만 생성해서는 데일리 노트가 **관리 도구** 가 되지 못한다는 게 명확해졌습니다. 이월·완료·드롭·보관 같은 상태 전이를 자동으로 다뤄주고, 하루/한 달 단위로 종합 문서에 기록해주는 **관리 체계** 가 필요했고, 그래서 이 프로젝트를 만들었습니다.

---

## 어떻게 동작하나

사용자가 하는 일은 딱 두 가지입니다.

- 오늘 노트에 할일과 메모를 자유롭게 적기
- 끝낸 항목은 체크 표시, 특별히 처리하고 싶은 항목엔 마커 붙이기 (`#장기`, `#보관`, `[-]`)

시스템이 다음 날 아침에 하는 일은 이렇습니다.

1. 로그인 순간 자동 실행되어 오늘 날짜의 노트를 새로 만듭니다.
2. 어제 노트를 읽어 항목별 상태를 분류합니다.
3. **완료**한 항목은 그대로 어제 노트에 남기고, 월간 종합 문서에도 기록합니다.
4. **미완료** 항목은 오늘 노트의 "이월된 할일" 섹션으로 옮기며, 며칠째 이월되고 있는지 표시합니다.
5. **3~4일 이월**된 항목엔 색깔 경고를 붙여 눈에 띄게 하고, **5영업일 초과**되면 자동으로 월간 드롭 문서로 이동시킵니다.
6. `#보관` 마커가 붙은 항목은 상시 보관함 문서로, `[-]` 마커는 즉시 드롭 처리합니다.

사용자가 신경 쓸 것은 "오늘 뭐 할지 적고 끝난 것에 체크" 뿐이고, 그다음의 정리·집계·이동은 모두 자동입니다.

옵시디언 앱에 종속되지 않습니다. 마크다운 파일과 폴더 구조만 다루므로 다른 마크다운 에디터에서도 열람·편집 가능합니다. `[[wikilink]]` 하나만 옵시디언 전용 문법입니다.

## 주요 기능

### 상태 전이 자동 처리

| 상태 | 표기 | 의미 |
|---|---|---|
| 활성 | `- [ ] 할일` | 오늘 새로 추가한 항목 |
| 이월 (1~2일) | `- [ ] 할일 (N일째 이월, MM-DD~)` | 어제 못 끝내고 넘어온 항목 |
| 보류 (3~4일) | `🟠/🔴 - [ ] 할일 ... (드롭 예정입니다)` | 곧 자동 드롭될 항목 |
| 완료 | `- [x] 할일` | 사용자가 체크 → 월간 종합에 로그 |
| 드롭 | 월간 드롭 문서로 이동 | 5일 초과 또는 `[-]` 마커 |
| 보관 | 보관함 문서로 이동 | `#보관` 마커 |

### 월간 종합·드롭 문서 자동 갱신

매달 한 번 열어 보면 그달의 완료 이벤트, 드롭 이벤트, 보관 이벤트가 날짜별로 정리되어 있습니다. 별도로 손대지 않아도 데일리 노트 생성 흐름 안에서 함께 갱신됩니다.

### macOS 로그인 시 자동 실행

launchd 로 등록되어 맥북을 켤 때마다 오늘 노트가 자동으로 만들어집니다. 사용자가 매일 아침 명령어를 치거나 앱을 열 필요가 없습니다.

### 부팅 직후 실패 자동 방어

macOS 는 부팅 직후 잠깐 동안 파일 접근을 제한하는 시기가 있어, 자동 실행이 첫 시도에서 튕길 수 있습니다. 감독 스크립트가 이걸 감지해 조건이 준비될 때까지 기다렸다가 재시도하고, 최종 실패 시엔 진단 파일을 남기고 알림을 띄웁니다. 상세는 아래 "부팅 시 실패했다면" 절.

### 진단 도구

`doctor` 명령어로 설치 상태를 언제든 점검할 수 있습니다. 리포 위치, 환경 변수, 볼트 접근, launchd 등록, 최근 로그를 한 화면에 정리해 보여줍니다.

---

## 요구사항

- **macOS**. 자동 실행에 launchd 를 사용하므로 macOS 전용입니다. Linux 에서는 systemd/cron 으로 대체할 수 있지만 미검증입니다.
- **Python 3.9 이상**. macOS 기본 탑재 `/usr/bin/python3` 를 그대로 쓸 수 있습니다.
- **옵시디언 볼트 또는 임의의 마크다운 노트 폴더**. 옵시디언 앱 없이도 동작합니다.

## ⚠️ 설치 전 반드시 알아둘 것

**리포지토리를 다음 폴더 안에 클론하지 마세요.**

- `~/Documents/`
- `~/Desktop/`
- `~/Downloads/`
- 아이클라우드 드라이브 (`~/Library/Mobile Documents/`)

macOS 는 이 폴더들을 문지기 시스템(TCC) 으로 잠그기 때문에, 안에 놓인 스크립트는 **부팅 직후 자동 실행이 "Operation not permitted" 로 실패**합니다. 사용자가 로그인 후 수동으로 실행하면 되지만, 이 프로젝트의 목적이 "매일 아침 자동 실행" 이라 큰 의미가 없습니다.

**권장 위치**: `~/daily-note-system/` (홈 폴더 바로 아래)

아래 `install.sh` 가 실행 위치를 자동 검사해서 잠긴 폴더 안이면 설치를 중단합니다. 배경 상세는 [docs/llm-guide.md](docs/llm-guide.md) 의 "부록 A" 를 참고하세요.

## 설치

### 1. 클론

반드시 홈 폴더 바로 아래로 클론합니다.

```bash
git clone https://github.com/KiimDoHyun/daily-note-system.git ~/daily-note-system
cd ~/daily-note-system
```

### 2. 설치 스크립트 실행

```bash
./install.sh
```

실행하면 다음을 자동으로 처리합니다.

- 현재 위치가 잠긴 폴더 안인지 검사 (안이면 즉시 중단)
- 옵시디언 볼트 경로 확인 (없으면 입력 요청)
- 로그 디렉토리 생성
- launchd 설정 파일 생성 및 등록

볼트 경로를 미리 지정하고 싶다면 인자로 넘기면 됩니다.

```bash
./install.sh "$HOME/Documents/Obsidian Vault"
```

### 3. 전체 디스크 접근 권한 부여 (필수)

파이썬이 볼트 폴더에 접근하려면 macOS 문지기 승인이 필요합니다. GUI 로 한 번 설정하면 이후 계속 유지됩니다.

1. **시스템 설정 → 개인정보 보호 및 보안 → 전체 디스크 접근 권한**
2. `+` 클릭 → `Cmd+Shift+G` → `/usr/bin/python3` 추가
3. 토글 켬

### 4. 즉시 실행 시험

부팅을 기다리지 않고 지금 바로 한 번 실행해 봅니다.

```bash
launchctl kickstart -k "gui/$(id -u)/com.example.daily-note"
```

성공하면 오늘 날짜의 노트가 볼트 안 `Notes/YYYY-MM/N주차/` 아래에 생성됩니다.

### 5. 설치 상태 진단

문제가 있는지 확인하려면:

```bash
/usr/bin/python3 ~/daily-note-system/daily_note.py doctor
```

리포 위치, 환경 변수, 볼트 접근, launchd 등록, 로그 파일 상태를 한꺼번에 리포트해 줍니다.

## 사용법

### 데일리 노트 섹션

노트는 세 개의 최상위 섹션으로 나뉩니다.

- `## 📌 할일` — 오늘 새로 시작할 항목
- `## ✅ 이월된 할일` — 자동으로 채워짐. 어제부터 넘어온 항목
- `## 💬 메모` — 자유 서술. 이월 대상 아님

**주의**: 하위 항목이나 메모는 반드시 들여쓰기(탭 또는 공백) 후 작성하세요. 들여쓰기 없으면 새로운 최상위 블록으로 인식됩니다.

### 마커

할일 라인에 다음 마커를 붙여 특수 처리를 지정할 수 있습니다.

- `#장기` — 5영업일 드롭 규칙에서 제외. 무한 이월
- `#보관` — 다음 날 노트 생성 시 보관함 문서로 이동
- `[-]` — 다음 날 노트 생성 시 즉시 드롭 (체크박스 자리에 `-` 를 넣습니다)

### CLI 명령어

launchd 가 자동 실행하는 것 외에, 수동으로 조작하고 싶을 때 사용합니다.

```bash
python3 daily_note.py create                  # 오늘 데일리 노트 생성 (launchd 기본)
python3 daily_note.py dry-run                 # 파일 수정 없이 예상 동작만 출력
python3 daily_note.py force 2026-09-15        # 특정 날짜 강제 재생성
python3 daily_note.py recompute 2026-09       # 특정 월 종합 상단 요약 재계산
python3 daily_note.py doctor                  # 설치 환경 진단 리포트
```

`--today YYYY-MM-DD` 옵션으로 "오늘" 을 임의 날짜로 오버라이드할 수 있습니다. 테스트나 과거 노트 재생성에 유용합니다.

## 부팅 시 실패했다면

맥북을 켜자마자 자동 실행이 실패하는 경우가 있습니다. 감독 스크립트가 자동으로 대응합니다.

1. 사용자 세션(Finder) 이 뜰 때까지 최대 30초 대기
2. 파이썬 실행 실패 시 5초 간격으로 최대 10회 재시도
3. 그래도 실패하면 **진단 파일을 남기고 알림 표시**

진단 파일 위치: `~/.local/state/daily-note/last-failure.txt`

알림을 받은 뒤 대응 순서는 이렇습니다.

1. 진단 파일을 열어 어디서 실패했는지 확인
2. `doctor` 명령으로 환경을 재점검
3. 세션이 살아있으면 즉시 재시도:
   ```bash
   launchctl kickstart -k "gui/$(id -u)/com.example.daily-note"
   ```

첫 실패 알림이 조용히 사라졌다면 macOS 알림 권한 팝업을 놓쳤을 수 있습니다. **시스템 설정 → 알림** 에서 "스크립트 편집기" 항목이 허용 상태인지 확인하세요.

## 폴더 구조

이 저장소:

```
daily-note-system/
├── daily_note.py           # CLI 진입점
├── install.sh              # 설치 자동화 (위치 검사 포함)
├── lib/                    # 라이브러리 모듈
├── launchd/
│   ├── com.example.daily-note.plist.template
│   └── run-with-retry.sh   # 부팅 시 감독 스크립트 (재시도 + 실패 알림)
├── tests/                  # unittest 테스트
└── docs/design.md          # 설계 문서
```

배포 시 볼트 안:

```
YourVault/
└── Notes/
    ├── 보관함.md
    ├── 2026-09/
    │   ├── 2026-09 종합.md
    │   ├── 2026-09 드롭.md
    │   ├── 1주차/
    │   │   └── 📅 2026-09-01.md
    │   └── 2주차/...
    └── 2026-10/...
```

## 환경 변수

| 변수 | 필수 | 설명 |
|---|---|---|
| `DAILY_NOTE_VAULT_ROOT` | O | 볼트 루트 절대 경로 |
| `DAILY_NOTE_NOTES_SUBDIR` | X | 볼트 안 노트 하위 폴더 (기본 `Notes`) |
| `DAILY_NOTE_LOG_DIR` | X | 로그 디렉터리 (기본 `~/.local/state/daily-note`) |
| `DAILY_NOTE_LABEL` | X | launchd Label (기본 `com.example.daily-note`) |
| `DAILY_NOTE_MAX_ATTEMPTS` | X | 감독 스크립트 재시도 횟수 (기본 10) |
| `DAILY_NOTE_RETRY_INTERVAL` | X | 재시도 간격 초 (기본 5) |
| `DAILY_NOTE_FINDER_WAIT` | X | Finder 대기 초 (기본 30) |
| `DAILY_NOTE_PYTHON` | X | 파이썬 실행 파일 경로 (기본 `/usr/bin/python3`) |
